# Beat sheet

A direct-response video ad is a short chain of beats. Each has one job. Most ads use five to eight of these, and the order varies.

| Beat | Job | Sounds like |
|---|---|---|
| Hook | Stop the scroll | "Can't poop on a GLP-1." |
| Callout | Tell the right viewer it is for them | "If you've been on it more than a month…" |
| Problem | Make the pain concrete | "By week three I was going once every four days." |
| Agitation | Show what it costs | "I was skipping dinners with friends." |
| Failed fixes | Dismiss what they already tried | "Fibre pills did nothing. Prunes, nothing." |
| Turn | The moment things changed | "Then my sister sent me these." |
| Mechanism | How the product works | "It's the one with all three fibres your gut needs." |
| Demonstration | Show it in use | Pours it, eats it, applies it |
| Proof | Evidence | "Day five. Regular." / reviews on screen |
| Authority | A credible voice | "My GI nurse friend takes it too." |
| Objection | Answer a doubt | "And no, it doesn't taste like vitamins." |
| Offer | What they get | "The starter pack is half off right now." |
| Urgency | Why now | "They sold out twice last month." |
| Call to action | The one thing to do | "Tap below and try the starter pack." |

## How to split a transcript

1. Read it once through.
2. Mark every point where the job of the sentence changes. That is a beat boundary.
3. Label each stretch with one beat. If a line does two jobs, give it the one that matters more to the sale.
4. Note where each beat falls: timestamps if present, otherwise position.
5. List the beats from the table above that the ad does not use.

## Common shapes

| Shape | Order | Typical use |
|---|---|---|
| Problem first | Hook → Problem → Failed fixes → Turn → Mechanism → Proof → Offer → CTA | Health, supplements, skincare |
| Story | Hook → Story start → Agitation → Turn → Result → CTA | Creator testimonials |
| Demo | Hook → Demonstration → Mechanism → Proof → Offer → CTA | Gadgets, home, beauty tools |
| Comparison | Hook → Usual choice → Why it fails → This instead → Proof → CTA | Crowded categories |
| Offer first | Hook (deal) → What you get → Proof → Urgency → CTA | Sales, retargeting |
| List | Hook → Reason 1 → Reason 2 → Reason 3 → CTA | "3 reasons I switched" |

## What to notice

- **Seconds to the problem.** The second the problem is first named.
- **Where proof sits.** The beat where proof first appears, and what kind it is.
- **Who speaks.** A customer, the founder, an expert, a voice over footage.
- **Angles.** How many angles the script argues.
- **The close.** The action asked for, and how many times it is said.

## Writing the template

- One line per beat, with the beat name and a time range.
- Slots in square brackets, each asking for one specific thing.
- Keep the sentence rhythm of the original.
- Add a line for speaker and a line for visuals.
